## 0. ทำไมต้องมีแผนนี้

โครงการชุดแรกวิเคราะห์ที่ **Ny.7 จุดเดียว** — `analysis/goal4_all_stations_plan.md` เสนอขยายเป็นทุกจุด
รีวิวกับข้อมูลจริงแล้วพบว่าถูกทาง **แต่ยังไม่พร้อมลงมือ 3 ข้อ**:

1. ไม่มี raw data + สคริปต์ดึงเก็บไว้ → ข้อค้นพบพิสูจน์จาก repo ไม่ได้
2. ตาราง Δ ใช้ (น้ำสูงสุด − ต่ำสุด) ซึ่งปน **การปิดบาน** เข้าไป → ตัวเลขผิดเชิงวิธี
3. ประเมินความพร้อมของ Q / ฝน / วัตถุประสงค์ 2 สูงเกินจริง

แผนนี้คือทางเดินที่ **แก้ 3 ข้อนั้นก่อน** แล้วค่อยขยาย — และเป็นคำตอบว่า "การวิเคราะห์จะเหมือนเดิมหรือต่างจากเดิม"
