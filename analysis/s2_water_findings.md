# ตรวจน้ำด้วย Sentinel-2 optical วันเดียวกับ S1 (2 ต.ค. 69) — ผลและข้อจำกัด

## วิธี
`analysis/s2_water.py` — MNDWI = (B03 green − B11 SWIR1)/(B03+B11) > 0 · ตัดเมฆ/เงา/cirrus
ด้วย SCL (คง class 4/5/6/7) · อ่านบนกริด S1 30 ม. · พื้นที่ใน lowland <60 ม. เดียวกับ S1
ฉาก: S2B 2 ต.ค. 10:35 น. (S1 ผ่าน 06:09 น. — ห่างกัน 4.5 ชม.)

## ผล

| ค่า | คะแนน |
|---|---|
| ฟ้าโปร่งบนจังหวัด (SCL เข้ม — ไม่นับ thin cirrus) | **13.7%** เท่านั้น |
| น้ำที่ S2 เห็น (lowland, ในหน้าต่างโปร่ง) | **7.4 ตร.กม.** |
| น้ำที่ S1 เห็น (หน้าต่างเดียวกัน) | 1.4 ตร.กม. (รวม — หน้าต่างโปร่งส่วนใหญ่เป็นเมือง กฎ VH≤−20 ตัดพิกเซลสะท้อนซ้ำ) |
| S2-only (S1 มองข้าม) | **6.3 ตร.กม.** |
| threshold MNDWI −0.05 / 0 / +0.05 / +0.1 | 12.8 / 7.4 / 4.0 / 1.8 ตร.กม. |

รายอำเภอ (หน้าต่างโปร่ง): เมือง 4.6 · ปากพลี 2.5 · องครักษ์ 0.3 · บ้านนา 0.0

## การตีความ (ซื่อตรง)

1. **ทิศทางสนับสนุนข้อสรุปหลัก**: ในหน้าต่างที่เทียบได้ S2 เห็นน้ำมากกว่า S1 ~5.3 เท่า
   (7.4 vs 1.4) — สอดคล้องกับที่รายงานกำกับไว้เสมอว่า "ค่า S1 = ขอบล่าง เพราะเรดาร์
   มองข้ามน้ำตื้น/ขุ่น/ไหลแรง"
2. **แต่ตัวอย่างเล็กเกินใช้เป็นตัวเลขหลัก**: ฟ้าโปร่งจริงเพียง 13.7% (นิยามเข้ม — ตัด
   thin cirrus ที่บิด MNDWI ได้) และหน้าต่างโปร่งกระจุกอยู่เมือง/ปากพลี ไม่ครอบที่ราบท่วม
   หนักฝั่งองครักษ์/บ้านนา จึง**สรุปพื้นที่รวมจาก S2 ไม่ได้** — คงใช้ 363.6 (S1) เป็นค่าหลัก
   พร้อมกำกับ "ขอบล่าง"
3. Landsat ช่วงเดียวกัน: ไม่มีฉากใดครอบจังหวัดช่วงน้ำสูงสุด/หลังช่วงน้ำสูงสุด (path 129 รอบล่าสุด
   23 ก.ย. ก่อนช่วงน้ำสูงสุด — ดู data/21_landsat_optical/manifest.md)
