# การวิเคราะห์ภูมิประเทศ อ.เมือง นครนายก (จาก Copernicus DEM GLO-30)

> วิเคราะห์ 4 ต.ค. 2569 · ข้อมูล: Copernicus DSM 30 ม. (EPSG:4326, ความสูงอ้าง EGM2008 ≈ ระดับน้ำทะเลค่ากลาง) · ไฟล์ต้นทาง: data/08_dem_topography/raw/

## 1. โปรไฟล์ความสูงตามแนวแม่น้ำนครนายก (เขื่อน → ตัวเมือง → ท้ายน้ำ)

| จุด | ความสูง (ม.รทก.) |
|---|---|
| เขื่อนขุนด่านปราการชล (ต.หินตั้ง) | 115.5 |
| ธรรมศาลา (ทางเข้าเขื่อน) | 23.9 |
| Ny.1B บ้านเขานางบวช | 9.4 |
| กึ่งกลาง (เขานางบวช→เมือง) | 9.7 |
| **Ny.7 สะพานหน้าจวนผู้ว่าฯ (ใจกลางเมือง)** | **6.5** |
| ต.พระประแดง | 4.1 |
| อ.องครักษ์ (ท้ายน้ำ) | 3.9 |

→ แม่น้ำไหลลง ~9 ม. จากใกล้เขื่อนถึงตัวเมือง (~8 กม.) และลงอีก ~2.5 ม. ถึงองครักษ์ → พื้นที่ อ.เมือง เป็น**ที่ราบเชิงเขาค่อนข้างรับน้ำจากต้นน้ำโดยตรง**

## 2. การกระจายความสูงพื้นที่ อ.เมือง (กรอบประมาณ 14.10–14.36°N, 101.08–101.32°E รวมเชิงเขา)

- ควอร์ไทล์: p5=3.3 / p25=4.3 / **มัธยฐาน=9.2** / p75=28.4 ม. (p75 สูงเพราะรวมเชิงเขาใหญ่/เขาพนม)
- **พื้นที่ต่ำกว่าระดับต่าง ๆ**: <4 ม. = 21% · <6 ม. = 36% · **<8 ม. = 45%** · <10 ม. = 53% · <12 ม. = 58%

## 3. การตีความเชื่อมกับเหตุการณ์น้ำท่วม (ฉบับคร่าว — มีข้อจำกัดด้าน datum)

- ระดับพื้นที่รอบตัวเมืองส่วนใหญ่ 3–10 ม.รทก. · แม่น้ำ ณ จุดตัวเมือง ~5–6.5 ม.รทก.
- ระดับน้ำน้ำสูงสุดที่ Ny.7 (มาตรฐานสถานี) สูงขึ้น ~3.2 ม. จากฐาน (6→9.23) — ถ้าอ้างศูนย์สถานีใกล้ร่องน้ำ ระดับผิวน้ำน้ำสูงสุดจะอยู่ราว 8–9 ม.รทก. → **น้ำจะล้นเข้าพื้นที่ที่ต่ำกว่า ~8 ม. ซึ่งครอบคลุมราว 45% ของพื้นที่ อ.เมือง** — สอดคล้องกับภาพการท่วมกว้างในอัลบั้ม "อุทกภัย นครนายก 2569"
- ขั้นตอนถัดไป (ทำต่อ): แปลง datum จุดวัด Ny.7 ให้เที่ยง (หาค่าศูนย์สถานีจาก กช.) · ใช้ FABDEM (DTM ลบสิ่งปลูกสร้าง) แทน DSM · ซ้อนแผนที่น้ำท่วมจากภาพถ่าย/อัลบั้ม 668 ภาพ เพื่อเขียนขอบเขตจริง

## 4. ข้อจำกัดสำคัญ (ต้องกำกับทุกครั้งที่อ้างผลนี้)

1. เป็น **DSM** (รวมต้นไม้/สิ่งปลูกสร้าง) ค่าความสูงจุดอาจสูงเกินพื้นดินจริง 2–5 ม. ในบริเวณมีต้นไม้/อาคาร — ตัวเลข "พื้นที่ต่ำกว่า X ม." จึงเป็น**ค่าประมาณล่าง**ของความเสี่ยง
2. ระดับแม่น้ำที่จุดวัดใช้มาตรฐานเฉพาะสถานี ไม่ใช่ ม.รทก. — การเทียบกับ DEM ยังเป็นเชิงประมาณ
3. กรอบพื้นที่ อ.เมือง เป็น bbox ประมาณ ไม่ใช่เขตแดนการปกครองจริง
