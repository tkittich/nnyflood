> ผ่านการตรวจ 3 ทาง · รายละเอียดเต็มอยู่ใน `analysis/gistda_georef_findings.md`
> ไฟล์บันทึกด้านล่างเก็บไว้เป็นประวัติการทำงาน (รวมข้อสันนิษฐานที่ภายหลังพิสูจน์ว่าผิด)

**ข้อเสนอเดิมสองข้อที่พิสูจน์ว่าใช้ไม่ได้** (เก็บไว้เตือนความจำ):
- ❌ "SIFT/ORB จับคู่ GISTDA basemap กับ Sentinel-2" — basemap ของ GISTDA เป็น **แผนที่เวกเตอร์**
  ไม่ใช่ภาพถ่าย · ไม่มี texture ให้จับคู่ · และ S2 วันที่ 2 ต.ค. เมฆ ~52% (วันพีค 27 ก.ย. เมฆ 100%)
- ❌ "อ่าน graticule ไม่แม่นพอ" — จริง ๆ แม่นมากพอ **ถ้าวัดตำแหน่งขีดสเกลด้วยโปรแกรม**
  (ปัญหาอยู่ที่การอ่านตำแหน่งจากภาพที่ผ่านการย่อ ไม่ใช่ที่ graticule เอง)

## สิ่งที่รู้แล้ว (การตรวจจริงรอบนี้ — แม่นกว่ารอบก่อนมาก)

1. **กรอบแผนที่**: ซ้าย x=1602 (เส้นดำยาว detect ได้) · บนเริ่มแถบ map ที่ y≈618 (เส้นน้ำเงิน = ขอบกรอบ) · ขวา/ล่างยังไม่วัด
2. **ป้าย graticule ที่อ่านได้ (พิกัด pixel จริง)**:
   - "101°0'0"E" ที่ x≈3164–3197 (กลางป้าย) — ยืนยันจาก 2 crops อิสระ (_top_strip, _gc_dam)
   - "101°20'0"E" ที่ x≈5240–5305 (_top_strip2, _top_s2)
   - → สเกล lon ≈ (5270-3180)/0.3333° = **6270 px/° ≈ 17.7 ม./px**
   - "14°20'0"N" ที่ y≈2495 (_left_strip2 — ต้องระวัง scale ของภาพ display!)
3. **บทเรียนครั้งใหญ่**: การอ่านตำแหน่งจากภาพที่ผ่าน Read tool ต้องคูณ scale ของ display กลับเสมอ (Read ย่อภาพกว้าง >1500 px) — รอบก่อนผิดเพราะลืม (อ่าน 2455/1440 ทั้งที่จริง 3180/2495)
4. **ขอบซ้ายบนของ map ครอบถึง สระบุรี** (อ.เสาไห้/เขาพระพุทธฉาย) — ไม่ใช่เริ่มที่นครนายก
5. **จุดจับคู่ที่ชัดที่สุดสำหรับ fit**: เส้นประดำ "ขอบจังหวัดนครนายก-ปราจีนบุรี" ใน crop _gc_town3 (2300-3100, 2200-3000) — จุดหักเด่น: (320,495)+(320,800) เส้นตั้ง, (530,290) มุมหัก, (700,40) — ต้องจับคู่กับ OSM ring (ขอบตะวันออกเฉียงใต้ ลุ่ม 101.1-101.3 / 14.0-14.2)
6. **สเกล bar** (0-4.25-8.5 กม.) อยู่ซ้ายล่างใต้กรอบ (~original x 1210-1670, y 3260) ยังไม่ได้วัดความยาว px

## ~~ขั้นตอนต่อไป (15-20 นาที)~~ — ยกเลิก (ทำเสร็จแล้วด้วยวิธีอื่น)

1. หา "จุดหัก" ใน OSM ring (ขอบตะวันออกเฉียงใต้): คำนวณมุมหักทุกจุด ring กรองมุม >90° ในบริเวณ lon 101.1-101.3, lat 14.0-14.2
2. จับคู่ 3 จุดหักจากข้อ 5 กับจุดหัก OSM (ลำดับ ring ติดกัน + ระยะสัมพัทธ์ตรงกัน) → fit affine 4 พารามิเตอร์ (north-up, sx,sy ต่างกันได้)
3. **validate**: warp overlay ขอบจังหวัด OSM บน map — ต้องทับเส้นประดำทั้งลุ่ม + แม่น้ำ แล้วจึงใช้ได้
4. สี mask น้ำท่วม (ฟ้า น้ำท่วม PAI = ฟ้าสว่าง, น้ำหลัก = ฟ้าเข้ม — สุ่มสีจาก legend swatches) → นับพื้นที่ในขอบจังหวัด → เทียบ 380 ตร.กม. กับ S1 436.3/306.9
5. อัปเดต manifest_gistda_map_product.md (ลบ "ยังไม่สำเร็จ") + รายงานวิชาการ §georeference + commit

## รอบ corner-matching อัตโนมัติ (6 ต.ค. — ยังไม่ถึงระดับใช้งาน · ถูกแทนที่แล้ว)

- วิธี: จุดหัก OSM ring 494 จุด (ภูมิภาค) × GCP 3 จุดที่ผมอ่านจาก crop → ทดสอบ 76.6 ล้าน triples (กรองด้วยสเกล/ระยะ)
- ผู้ชนะ: median 55.7 px · จุดใกล้เส้น <20px เพียง 28% — **ยังไม่ล็อก** (เกณฑ์ผ่านควร <20 px median, >70%)
- สาเหตุ: GCP อ่านมือคลาด ±15-30 px + เส้นดำใน map มีถนนปนใน target ทำ chamfer หลอก
- **ทางถัดไปที่น่าลงทุนที่สุด**: SIFT/ORB feature matching ระหว่าง GISTDA basemap กับ **Sentinel-2 true color (มี georef ในตัว)** ฉากใกล้เคียง — ข้อมูล S2 มีแล้วในชุด 18 (2 ต.ค. บางแถบโปร่ง) — หรือ QGIS manual GCP โดยผู้ใช้ (~10 นาที แน่นอนที่สุด)
