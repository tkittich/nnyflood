## โครงสร้างไฟล์ต้นฉบับ (สำคัญ — อ่านก่อนใช้)

ชีตเดียว ตั้งชื่อตามรหัสสถานี · แถว 1–2 = หัวตาราง · **ข้อมูลเริ่มแถว 2**

| คอลัมน์ | ความหมาย |
|---|---|
| `I:J`, `K:L`, `M:N` | **เส้นสำรวจปัจจุบัน (ปีน้ำ 2568/2025) แบ่งเป็น 3 ช่วง offset ต่อเนื่องกัน** — `ระยะ -ม.` (offset) และ `ระดับ-ม.(รทก.)` |
| `R:S` | ปี 2568 (= ซ้ำกับ I:J ใช้เป็นคอลัมน์เทียบ) |
| `T:U` | ปี 2567 |
| `V:W` | ปี 2565 |
| `Z:AA` | ปี 2566 |

- ช่อง `ระยะ` มี **ป้ายกำกับปนกับตัวเลข** เช่น `"0   R1    บน"`, `"50  ท้องน้ำ"`, `"23.50 ผิวน้ำซ้าย"` → ต้องดึงตัวเลขนำหน้าและเก็บป้ายแยก (สคริปต์ `analysis/rid_cross_section_extract.py` ทำให้แล้ว)
- `R1`/`R2` = จุดอ้างอิงตลิ่ง/ตอม่อสะพาน ฝั่งซ้าย(0) และขวา(100) · `บน`/`ล่าง` = ระดับบน/ล่างที่ offset เดียวกัน (หน้าตัดดิ่ง)
- `ท้องน้ำ` = จุดต่ำสุด (thalweg) · `ผิวน้ำซ้าย`/`ผิวน้ำขวา` = ขอบน้ำ ณ วันสำรวจ

## ตรวจความถูกต้องภายใน (ผ่าน)

ที่ Ny.7 ระดับที่ป้าย `ผิวน้ำซ้าย` (offset 23.50) = **2.624 ม.รทก.** และ `ผิวน้ำขวา` (offset 76) = **2.624 ม.รทก.** — **เท่ากันพอดี**
→ ยืนยันว่า 3 ช่วงคอลัมน์ใช้ datum เดียวกันจริง (รทก.) และเส้นสำรวจต่อเนื่องกัน ใช้ได้

## ข้อจำกัดที่ต้องระบุเมื่อใช้

1. **ช่วงสำรวจจำกัด** (Ny.7 = −60..150 ม., Ny.1B = −60..160 ม.) — ที่ระดับน้ำสูงสุดเหตุการณ์ น้ำ**ล้นออกนอกช่วงสำรวจทั้งสองสถานี** → พื้นที่/Q ที่คำนวณได้เป็น **ค่าต่ำสุด (lower bound)** ไม่ใช่ค่าจริง
2. **เป็นหน้าตัดที่สะพาน** (Ny.7 = สะพานหน้าบ้านผู้ว่าฯ) — สันตลิ่งที่วัดได้อาจเป็น **ตอม่อ/ทางขึ้นสะพาน** ไม่ใช่ตลิ่งธรรมชาติ
3. **สำรวจปีน้ำ 2568 (2025)** — ก่อนเหตุ ก.ย. 2569 หนึ่งปี (ใช้ได้ แต่ควรระบุ)
4. ยังไม่ได้ตรวจกับภาพถ่าย/แผนที่ว่าทิศ offset ฝั่งใดคือฝั่งเมือง
