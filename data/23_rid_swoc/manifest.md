# manifest — data/23_rid_swoc (ข้อมูลอ่างเก็บน้ำและโทรมาตร กรมชลประทาน SWOC)

> เพิ่ม **17 ต.ค. 2569** — ค้นพบแหล่งข้อมูลปฐมภูมิ: ศูนย์ปฏิบัติการน้ำอัจฉริยะ กรมชลประทาน (Smart Water Operation Center - SWOC)
> และระบบฐานข้อมูลน้ำในอ่างเก็บน้ำ (RID Reservoir Database) ที่ <https://swoc.rid.go.th/> และ <https://app.rid.go.th/reservoir/>
> เป็นข้อมูล **อ่างเก็บน้ำขนาดใหญ่ 35 แห่ง, อ่างเก็บน้ำขนาดกลาง 461 แห่งทั่วประเทศ, และรูปตัดขวางลำน้ำจริงจากโทรมาตร**
> พร้อมอนุกรมเวลารายวันประวัติศาสตร์ย้อนหลังลึกที่สุดเท่าที่มีในฐานข้อมูล (2009–2026 สำหรับอ่างขนาดกลาง และ 1995–2026 สำหรับเขื่อนใหญ่)
> เอกสารอ้างอิงเชิงลึกฉบับเต็ม: [docs/RID_SWOC_GUIDE.md](file:///e:/theera/code/flood/docs/RID_SWOC_GUIDE.md)

## ต้นทาง

1. **ระบบฐานข้อมูลน้ำในอ่างเก็บน้ำ กรมชลประทาน**:
   - URL หลัก: <https://app.rid.go.th/reservoir/>
   - API เขื่อนใหญ่ (GeoJSON): `https://app.rid.go.th/reservoir/api/damsGeojson`
   - API อนุกรมเวลาเขื่อนใหญ่: `https://app.rid.go.th/reservoir/api/dam?dam_id={id}&date_start={start}&date_end={end}`
   - API อ่างขนาดกลาง (GeoJSON): `https://app.rid.go.th/reservoir/api/rsvmiddlesGeojson?date_start={date}&date_end={date}`
   - API อนุกรมเวลาอ่างขนาดกลาง: `https://app.rid.go.th/reservoir/api/rsvmiddle?rsvmiddle={cresv}&date_start={start}&date_end={end}`
2. **ระบบบริการเว็บโทรมาตรอุทกวิทยา กรมชลประทาน**:
   - URL: <https://hyd-app-db.rid.go.th/webservice/HDService.svc>
   - เมทาดาทาสถานี: `POST /getStationFromStationCode`
   - รูปตัดขวางลำน้ำจริง: `POST /GetCrosssectionFromStationID`
3. วิธีดึง: สคริปต์ [analysis/common_fetch_rid_swoc.py](file:///e:/theera/code/flood/analysis/common_fetch_rid_swoc.py) (ไม่ต้อง authentication / ไม่ต้องใช้ API key)

## สรุปข้อค้นพบทางอุทกวิทยาที่สำคัญสำหรับโปรเจกต์

1. **อ่างเก็บน้ำขนาดกลาง 6 แห่ง จ.นครนายก ในเหตุการณ์น้ำท่วม 26–29 ก.ย. 2569**:
   - ความจุเก็บกักรวมของทั้ง 6 อ่างอยู่ที่ **26.96 ล้าน ลบ.ม.** (คิดเป็น **12.0%** ของเขื่อนขุนด่านฯ 224 ล้าน ลบ.ม.)
   - **อ่างเก็บน้ำทรายทอง (`rsv383`)**: น้ำล้นเต็ม 100% ตั้งแต่ 26 ก.ย. (106.1%) และพีคที่ 107.65% วันที่ 27 ก.ย. โดยระบายน้ำล้นออก $0.455\text{ ล้าน ลบ.ม./วัน}$
   - **อ่างเก็บน้ำคลองวังบอน (`rsv384`)**: น้ำล้นเต็มความจุ (100.8% - 101.6%) ตลอดช่วง 26–28 ก.ย. ระบายออก $0.17 - 0.24\text{ ล้าน ลบ.ม./วัน}$
   - **อ่างเก็บน้ำห้วยปรือ (`rsv380`, 8.87 ล้าน ลบ.ม.)**: ช่วยชะลอน้ำได้มาก โดยรับน้ำเข้าพีค $0.577\text{ ล้าน ลบ.ม./วัน}$ วันที่ 27 ก.ย. แต่ระบายออกเพียง $0.108\text{ ล้าน ลบ.ม./วัน}$ (กักน้ำไว้ในอ่างจนระดับเพิ่มจาก 81% เป็น 92%)
   - **อ่างเก็บน้ำคลองกลาง (`rsv386`, 3.10 ล้าน ลบ.ม.)**: กักน้ำไว้ได้ 100% ในช่วง 26–28 ก.ย. (ไม่มีการระบายออก) ทำให้น้ำในอ่างเพิ่มจาก 74.8% สู่ 95.1%
   - รวม 4 วัน ทั้ง 6 อ่างช่วยหน่วงน้ำไว้ในอ่างได้สุทธิ **2.357 ล้าน ลบ.ม.** (48.8% ของน้ำหลากที่ไหลเข้า)
2. **รูปตัดขวางลำน้ำ Ny.1B และ C.2**:
   - ยืนยันค่าความจุลำน้ำสูงสุดทางการของกรมชลประทาน: Ny.1B อยู่ที่ $266.90\text{ ม.}^3/\text{วิ}$ (ระดับตลิ่ง $8.81\text{ ม.}$) และ C.2 นครสวรรค์ อยู่ที่ $3,735\text{ ม.}^3/\text{วิ}$ (ระดับตลิ่ง $25.70\text{ ม. รทก.}$)
3. **ความลึกของประวัติเขื่อนย้อนหลัง**:
   - เขื่อนขุนด่านปราการชล: ย้อนหลังได้ถึงวันแรกของการกักเก็บ 1 ม.ค. 2005 (7,811 วันต่อเนื่อง)
   - เขื่อนป่าสักชลสิทธิ์: ย้อนหลังได้ถึง 1 ม.ค. 2003 (8,425 วันต่อเนื่อง)
   - อ่างเก็บน้ำขนาดกลางทั้ง 6 แห่ง: ย้อนหลังได้ถึง 3 ม.ค. 2009 (6,258 วันต่อเนื่องต่ออ่าง)
