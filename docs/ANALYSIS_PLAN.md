## ภาพเหตุการณ์ที่ยืนยันจากข้อมูลแล้ว (จุดตั้งต้นของทุกการวิเคราะห์)

- ฝนสถานีนครนายก 12–29 ก.ย. 69 สะสม ~1,070 มม. (ฝนสูงสุด 144 มม. วันที่ 26, 104.8 วันที่ 25, ระลอกสอง 105+108 วันที่ 28–29)
- เขื่อน: ร่องเหลือ 24.92 ลลบ.ม. (2 มิ.ย.) → เหนือ URC ตั้งแต่ 30 ส.ค. (36 วันติด) → เต็มสุด 224.34 ลลบ.ม. (27 ก.ย.)
- ปล่อย: ฐาน 1.27 ลลบ.ม./วัน จนถึง 23 ก.ย. → 2.2 (25) → 4.6 (26) → สูงสุด 31.7 (27) → 19.4 (28) → 13.4 (29) → ลด
- น้ำเข้า: น้ำสูงสุด 37.4 ลลบ.ม./วัน (27 ก.ย.)
- แม่น้ำ: Ny.7 ตัวเมือง น้ำสูงสุด 9.23 ม. (27 ก.ย.) จากฐาน ~6 · Ny.1B ใกล้เขื่อน ~6 → 11.07 (26–27)

## คำถาม D — โมเดลทำนายระดับน้ำ Ny.7 และบริหารด้วยพยากรณ์ (เป้าหมาย 4)

**สถานะ: ทำแล้วระดับ 1 เสร็จสมบูรณ์** (แผนเต็ม analysis/goal4_prediction_model_plan.md)

- D1 โมเดลทำนายระดับ: ทดสอบ persistence vs สูตรเส้นตรง 11 ตัวแปร vs GBDT (ฝึก 5 ฤดู 11,221 ชม. / ทดสอบกลางเหตุการณ์) → **สูตรเส้นตรงดีสุดที่ระยะใช้งานจริง +6/+24 ชม.** (RMSE เหตุการณ์ 30.0/117.6/163.7 ซม. @+6/24/48 ชม.) แต่ **ไม่ชนะทุกระยะ** — ที่ +24 ชม. persistence ดีกว่า (101.8) และที่ +48 ชม. GBDT ดีกว่า (140.6) โดยที่ +48 ชม. ทุกโมเดลพังเท่ากัน (1.4–1.7 ม.) · GBDT ล้มที่ระยะสั้นเพราะทำนายนอกช่วงฝึกไม่ได้ · ฝนพยากรณ์เป็นอินพุต **ไม่ช่วยที่ +24 ชม.** (GFS 111.2 ≈ ฝนสังเกต 116.4 · แพ้ persistence 101.8) ช่วยเฉพาะ +6 ชม. · ฟีเจอร์ฝนคือหน้าต่าง n วันย้อนหลังบนอนุกรมรายวัน กันข้อมูลอนาคตรั่ว (ดู analysis/goal4_model_v1_findings.md)
- D2 สถานการณ์บริหารด้วยพยากรณ์ — *ชื่อเรียกข้ามเอกสาร: R1 = qa5 "ทำตาม URC" · M2 = qa5 "แก้ไข URC" · M3 = qa5 "แบบระมัดระวัง" · M4 = M3 + ระบายลำน้ำ* (คุมความจุอ่าง ≤225.4 ทุกแผน): จริง ~12 ลลบ.ม./65±6 ชม. → R1 กฎ URC อย่างเดียว −55%/18±6 ชม. → M2 ปรับระดับล่วงหน้า(ระบายออกมากก่อนพายุ 84) −93%/8±6 ชม. → **M3 แบบระมัดระวัง(ระบายออกล่วงหน้า ~13) −93%/9±6 ชม. = ข้อค้นพบหลัก: "หยุดปล่อย 26–28 ก.ย." สำคัญกว่าความลึกการระบายน้ำออกจากอ่าง** → **น้ำสูงสุด: R1/M1 ไม่เปลี่ยนอย่างมีนัย** (แบบจำลองให้ +0.50 ม. แต่น้อยกว่ากรอบ ±0.85 ม. จาก rating ±18%) → M4 = M3 + ระบายลำน้ำออกปลายน้ำล่วงหน้า: ส่งน้ำออกระบบ 5.2 ลลบ.ม. (~5% ของน้ำหลาก) — กระจายบนที่ราบท่วม 452 ตร.กม. → **ระดับสูงสุดลด ~1 ซม.** (5.2÷450) ในกรอบลำน้ำ 9.94 ตร.กม. ระดับลด ~52 ซม.
