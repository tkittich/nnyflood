### 0. dam_gate_timeline_sep2026.csv — ไทม์ไลน์การเปิดบานสปิลเวย์ช่วงเหตุการณ์
| คอลัมน์ | ความหมาย |
|---|---|
| date/time | วัน-เวลาของข้อมูล/โพสต์ |
| spillway_gates | สถานะการเปิดบาน (เช่น "2 บาน x 25 ซม.", "4 บาน x 50 ซม.") |
| storage_mcm / storage_pct | ปริมาณน้ำเก็บ ณ เวลานั้น (ตรวจไขว้กับ API แล้วหลายจุด) |
| tailwater_m | ระดับน้ำท้ายเขื่อน (ม.) |
| source_evidence | หลักฐานอ้างอิง (ไฟล์ภาพ/โพสต์) |
| notes | หมายเหตุ/ข้อควรระวัง (จุดที่มาจากข่าวหรือ OCR ต้องตรวจซ้ำ) |

**ข้อสรุปหลักของไทม์ไลน์**: ปิดสปิลเวย์ถึง 22 ก.ย. → เริ่มเปิด ~23 ก.ย. → 2 บาน 25 ซม. (24–26 ก.ย.) → ประกาศเพิ่มการระบายค่ำ 24 ก.ย. (มีผล 25 ก.ย. 08:00) → **4 บาน 50 ซม. ค่ำ 27 ก.ย.** → ลด 25 ซม. (28 ก.ย.) → 15 ซม. (3 ต.ค.)
