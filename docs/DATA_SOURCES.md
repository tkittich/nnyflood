## แหล่งข้อมูลภาคสนาม/ดาวเทียม (ส่วนเสริม)

### 4. ระบบโทรมาตรโครงการเขื่อน (khundan-tele.rid.go.th — โฮสต์จริงของ khundan.com) ✅
- `station_detail.php` POST **urlencoded** `n_id/date_from/date_to` — ต้องยิงตรงโฮสต์ (khundan.com จะ 301 แล้ว POST พัง)
- ช่วง ≤7 วัน → รายชั่วโมง / ยาวกว่านั้น → รายวัน 07:00 · ได้ทั้ง ระดับน้ำ(ม.รทก.), อัตราไหล Q, ฝน
- n_id: 61=Ny.1B · 62=Ny.7 · 63=ท้ายน้ำปตร.ท่าช้าง · 105=NY.3 · 16-74=ประตูคลอง/ฝาย

### 5. GISTDA แผนที่น้ำท่วม ✅
- **disaster.gistda.or.th** → shapefile ราย pass (RADARSAT-2, Sentinel-1) — ผู้ใช้ดาวน์โหลดมาให้ (data/manual → ประมวลผลใน data/12) · กรองจังหวัด: `PV_IDN==26` (นครนายก) · encoding ผสม: Reader(encoding='latin-1') แล้ว re-decode tis-620/cp874
- **FeatureServer GISTDA_FLOOD_7DAYS** (pherportal.moph.go.th/arcgis) = ชั้น AOI **แผ่นเล็ก 100 แผ่น ไม่ใช่เขตตำบล** — ห้ามใช้เป็นเขตจังหวัด/อำเภอ

### 6. Copernicus Data Space (CDSE) ✅
- Catalog ค้นได้ไม่ต้อง auth: `https://catalogue.dataspace.copernicus.eu/odata/v1/Products?$filter=OData.CSC.Intersects(area=geography'SRID=4326;POLYGON((...))') and startswith(Name,'S1') and ContentDate/Start gt ...` (ห้ามใช้ field Collection/CollectionName — 400)
- ดาวน์โหลด: browser.dataspace.copernicus.eu ต้อง login — **ผู้ใช้โหลดเอง** (Time Range เป็น **UTC** · ค้นด้วยแผนที่+ช่วงวันที่ · IAB เข้าไม่ได้เพราะ silent OIDC ถูกบล็อก)

### 7. OpenStreetMap (ผ่าน Nominatim) ✅
- ขอบเขตจังหวัด/อำเภอ GeoJSON: `nominatim.openstreetmap.org/search?q=<ชื่อ>&format=json&polygon_geojson=1&limit=1` (1 req/s, UA ระบุ) — province relation 1908787 + อำเภอ 4 ฉบับ เก็บที่ data/13_.../derived/ · สิทธิ์ ODbL (เชิงอ้างอิงระบุแหล่ง)


## แหล่งข้อมูลสนับสนุนโมเดลทำนายระดับน้ำ (เป้าหมาย 4)

- **ระบบโทรมาตรเขื่อนขุนด่านฯ** `http://khundan-tele.rid.go.th/station_detail.php` (POST n_id/date_from/date_to) — ยืนยันแล้วได้ **ราย 15 นาที** เมื่อช่วง ≤7 วัน ย้อนหลังถึงปี 2564 · สคริปต์ analysis/fetch_khundan_training*.py · ข้อจำกัด: เซนเซอร์ฝนสถานีใช้ไม่ได้ (อ่าน ~4 มม./ฤดู)
- **NASA POWER** `power.larc.nasa.gov/api/temporal/daily/point` (PRECTOTCORR) — ฝนรายวันกริด 0.5° ฟรีไม่ต้องยืนยันตัว ย้อนตั้งแต่ปี 1981 · ใช้เป็นฟีเจอร์ฝนของโมเดล (2 เซลล์: เหนือ/ใต้)
- **Open-Meteo** — 3 บริการ: `api.open-meteo.com/v1/forecast` (พยากรณ์ฉบับจริงล่าสุด ใช้เก็บสะสมรายวัน) · `historical-forecast-api` (ชุดเก็บถาวรย้อนหลังตั้งแต่ 2022 ใช้เทียบฝน 5 โมเดล GFS/ECMWF/ICON/GEM/JMA) · `previous-runs-api` (พยากรณ์ตามรอบย้อนหลัง เก็บ ~7 วันเท่านั้น — บทเรียนเหตุการณ์ ก.ย.) · windy.com API ต้องคีย์เสียเงิน
- **NASA GIBS** `gibs.earthdata.nasa.gov/wms/epsg4326/best/wms.cgi` — ภาพ MODIS/Terra สีจริงรายวัน ฟรี ไม่ต้องยืนยันตัว (ใช้ดึง 3 ก.ย.–2 ต.ค. 69)
- **สำนักงานโยธาธิการและผังเมืองจังหวัดนครนายก** — ภาพดาวเทียม 3 ภาพ (ผู้ใช้รับมา 4–5 ต.ค.) · ภาพ 2 ภาพหลังเป็นแผนที่ซูมระดับตำบล ไม่มีวันที่บนภาพ — ต้องสอบถามเพิ่มก่อนอ้างอิง
- **Google Flood Hub** — batchexecute RPC ไม่ต้อง API key (สูตรใน data/14_floodhub/manifest.md) · API ทางการต้องสมัครคีย์ฟรี
- **Sentinel-2 L2A** (CDSE เหมือน S1) — **tile ครอบที่ราบนครนายก = 47PQR** (ตรวจพิกัดแล้ว: point 101.22/14.20) · ระวัง: 47PPS = สระบุรี/ลพบุรี ไม่ใช่ของเรา (ผิดพลาดมาครั้งหนึ่ง)
