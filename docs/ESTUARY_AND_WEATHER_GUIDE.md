## 1. บทนำและกรอบแนวคิดการเชื่อมโยงระบบลุ่มน้ำ

ในการจำลองสภาพอุทกพลศาสตร์และการระบายน้ำหลากของลุ่มน้ำนครนายกและลุ่มน้ำเจ้าพระยาตอนล่าง การพิจารณาเฉพาะปริมาณน้ำในเขื่อนและแม่น้ำสายหลักไม่เพียงพอต่อการอธิบายปรากฏการณ์น้ำท่วมขัง ทั้งนี้เนื่องจากมีปัจจัยแวดล้อมที่ควบคุมจลนพลศาสตร์ของน้ำหลากอีก 4 ปัจจัยสำคัญ:

```
[ ฝนตกหนักโทรมาตร 4,593 จุด ] ──> [ น้ำหลากจำลอง GloFAS + ฝนล่วงหน้า ECMWF ]
           │                                      │
           ▼                                      ▼
[ ทางน้ำหลักและจุดบรรจบแม่น้ำ ] ──> [ ลิ่มความเค็มและสถานีสูบน้ำดิบประปา ]
           │                                      │
           ▼                                      ▼
[ อุปสรรคปลายน้ำ: คลื่นลม SWAN และระดับน้ำทะเลหนุนอ่าวไทย 31 สถานี ]
```

1. **การควบคุมการผลักดันน้ำเค็ม (Estuary Salinity Control)**: แม่น้ำเจ้าพระยาและบางปะกงจำเป็นต้องรักษาระดับการระบายน้ำขั้นต่ำเพื่อกดลิ่มความเค็มไม่ให้รุกเกินสถานีสูบน้ำดิบสำแล (จ.ปทุมธานี) ของการประปานครหลวง หากปล่อยน้ำน้อยไปน้ำประปาจะกร่อย หากปล่อยมากไปจะซ้ำเติมน้ำท่วมพื้นที่ลุ่มต่ำ
2. **เงื่อนไขขอบเขตปลายน้ำทางทะเล (Downstream Marine Boundary)**: คลื่นลมในอ่าวไทยและระดับน้ำทะเลหนุนทำหน้าที่เป็นแนวปิดกั้นทางชลศาสตร์ (Hydraulic Damming) ชะลอความเร็วในการระบายน้ำออกสู่อ่าวไทย
3. **การกระจายตัวของฝนจริงภาคพื้นดิน (Ground Telemetry Validation)**: ฝนจากสถานีโทรมาตรอัตโนมัติ 4,593 จุดทั่วประเทศ ช่วยยืนยันยอดฝนตกหนักจริงเทียบกับค่าประมาณการจากดาวเทียม
4. **การคาดการณ์น้ำท่าและอากาศล่วงหน้า (Predictive Flood Discharge)**: แบบจำลอง ECMWF IFS 16 วัน และแบบจำลองน้ำหลากโลก Copernicus GloFAS 16 วัน ให้ภาพอนาคตของมวลน้ำระลอกถัดไป พร้อมอนุกรมเวลาย้อนหลัง 17 ปี (2553–2569) เพื่อเปรียบเทียบระดับความรุนแรงของมวลน้ำ

### 2.1 สถาปัตยกรรม API และ Endpoint

#### ก) สแนปช็อตคุณภาพน้ำ 112 สถานีทั่วประเทศ
- **URL**: `https://api-v3.thaiwater.net/api/v1/thaiwater30/analyst/waterquality_load`
- **วิธีเรียก**: `GET` (ไม่ต้องใช้รหัสผ่านหรือโทเคน)
- **พารามิเตอร์**: ไม่มี
- **พารามิเตอร์ที่ตรวจวัด**:
  - `salinity`: ความเค็ม (กรัมต่อลิตร, g/L)
  - `conductivity`: การนำไฟฟ้า (ไมโครซีเมนต์ต่อเซนติเมตร, µS/cm)

  - `turbidity`: ความขุ่น (NTU)
  - `temperature`: อุณหภูมิน้ำ (°C)
  - `nitrate` / `ammonia`: ธาตุอาหารในน้ำ (mg/L)

#### ข) อนุกรมเวลาย้อนหลังความเค็มระดับ 10 นาที

- **วิธีเรียก**: `GET`
- **พารามิเตอร์**:
  - `waterquality_station_id`: รหัสสถานี (เช่น `5` พระนั่งเกล้า, `202` สำแล)
  - `param`: `salinity` หรือ `conductivity`
  - `start_datetime`: วันเวลาเริ่มต้น รูปแบบ `YYYY-MM-DD%20HH:MM`
  - `end_datetime`: วันเวลาสิ้นสุด รูปแบบ `YYYY-MM-DD%20HH:MM`
- **ข้อควรระวังสำคัญ**: ในไพทอน 3.14 ห้ามส่งอักขระเว้นวรรคดิบ (` `) ในสตริงคำค้น ต้องแปลงรหัส URL เป็น `%20` เสมอ มิฉะนั้นจะเกิดข้อผิดพลาด `InvalidURL`

### 3.1 สถาปัตยกรรม API
- **URL**: `https://api-v3.thaiwater.net/api/v1/thaiwater30/public/wave_forecast`

- **พารามิเตอร์**: ไม่มี (คืนข้อมูล 31 สถานีรอบอ่าวไทยและทะเลอันดามัน)

- สถานีวัดสิงห์ (C.12)
- สถานีท่าจีนปากน้ำ (THA009)
- สถานีแม่กลองปากน้ำ (MKG006)
- สถานีแท่นผลิตก๊าซธรรมชาติอ่าวไทย (PTTEP Offshore Rigs)

การรวมข้อมูลคลื่นลม SWAN และระดับน้ำขึ้น-น้ำลง ทำให้แบบจำลองชลศาสตร์สามารถกำหนดเงื่อนไขขอบเขตปลายน้ำได้อย่างสมบูรณ์

## 4. เสาที่ 3: ข้อมูลฝนสถานีโทรมาตรอัตโนมัติทั่วประเทศ (National Rainfall Telemetry)

- **ที่เก็บข้อมูล**: [data/26_national_rainfall_stations/](file:///e:/theera/code/flood/data/26_national_rainfall_stations/)
- **สคริปต์ดึงข้อมูล**: [analysis/common_fetch_rain_stations.py](file:///e:/theera/code/flood/analysis/common_fetch_rain_stations.py)
- **แหล่งที่มา**: คลังข้อมูลน้ำแห่งชาติ สสน. (บูรณาการ 5 หน่วยงาน: กรมชลประทาน, กรมอุตุนิยมวิทยา, กรมทรัพยากรน้ำ, กรุงเทพมหานคร, สสน.)

### 4.1 สถาปัตยกรรม API
- **URL**: `https://api-v3.thaiwater.net/api/v1/thaiwater30/public/rain_24h`
- **วิธีเรียก**: `GET`
- **ขนาดข้อมูล**: ประมาณ 7.4 MB (ครอบคลุมสถานีโทรมาตร 4,593 จุดทั่วประเทศ)
- **พารามิเตอร์ในแต่ละสถานี**:
  - `rain_24h`: ปริมาณฝนสะสม 24 ชั่วโมง (มม.)
  - `rain_1h`: ปริมาณฝนรายชั่วโมงล่าสุด (มม.)
  - `tele_station_name`: ชื่อสถานีโทรมาตรภาษาไทยและอังกฤษ
  - `agency`: รหัสและชื่อย่อหน่วยงานเจ้าของสถานี (RID, DWR, TMD, BMA, HII)
  - `geocode`: พิกัดภูมิศาสตร์ รหัสตำบล อำเภอ จังหวัด
  - `tele_station_lat` / `tele_station_long`: ละติจูดและลองจิจูดจริงของสถานี

### 4.2 บทบาทในการสอบเทียบแบบจำลอง
ข้อมูลชุดนี้เป็นตัวแทนการวัดฝนจริงภาคพื้นดินความหนาแน่นสูง ช่วยตรวจยืนยันความคลาดเคลื่อนเชิงพื้นที่ของฝนดาวเทียม (NASA POWER กริด 0.5° และ ERA5 กริด 0.25°) โดยเฉพาะในบริเวณแนวเทือกเขาดงพญาเย็น-เขาใหญ่ ซึ่งมีความแปรปรวนของยอดฝนสูงมากจากอิทธิพลลมปะทะภูเขา (Orographic Precipitation)

### 5.1 สถาปัตยกรรม API และการเรียกใช้

#### ก) พยากรณ์อากาศ ECMWF IFS ล่วงหน้า 16 วัน
- **URL**: `https://api.open-meteo.com/v1/forecast`
- **วิธีเรียก**: `GET`
- **พารามิเตอร์**:
  - `latitude`, `longitude`: พิกัดศูนย์กลางลุ่มน้ำ
  - `hourly=precipitation,rain,wind_speed_10m,wind_direction_10m,surface_pressure,cloud_cover`
  - `forecast_days=16`
  - `timezone=Asia%2FBangkok`

#### ข) พยากรณ์น้ำท่าแบบกลุ่ม (GloFAS Ensemble) ล่วงหน้า 16 วัน
- **URL**: `https://flood-api.open-meteo.com/v1/flood`
- **วิธีเรียก**: `GET`
- **พารามิเตอร์**:
  - `latitude`, `longitude`: พิกัดสถานีระบายน้ำหรือจุดบรรจบหลัก
  - `daily=river_discharge,river_discharge_mean,river_discharge_median,river_discharge_max,river_discharge_min,river_discharge_p25,river_discharge_p75`
