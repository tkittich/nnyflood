# แผนการทำแบบจำลอง 2 มิติ (HEC-RAS 2D) — นครนายก + ข้อมูลที่ยังขาดพร้อมความสำคัญ

> เป้าหมาย: แผนที่ชุด RODDSS (11 แผนที่) ทำซ้ำได้เอง — เส้นทางน้ำไหลหลาก · น้ำสูงสุด ·
> ความเร็วสูงสุด · ความแรงน้ำไหล · เวลาเริ่มท่วม >5/>25 ซม. · เวลาสูงสุด · ชั่วโมงท่วม >25/>50 ซม. ·
> เวลาลด <25/<5 ซม. — ตอบได้ทั้งฉากทัศน์ฝนจริงและฝนสมมุติ 500 มม./วัน
> ตั้งเป้าหมาย: **ลุ่มนครนายกเท่านั้นก่อน** (ข้อมูลครบสุด · มีตัวเลขตรวจ 452 ตร.กม. เป็นเป้าคาลิเบรต)
> · ลุ่มอื่นรอข้อมูลข้อ 1–3 ก่อน

## 3. ลำดับงานที่เสนอ

1. **แก้ DEM** — หา LiDAR ตัวจริง (มนุษย์/FOI) หรือ hybrid 30 ม.+contour (AI ทำได้)
2. **ดึง WorldCover + ตรวจความหยาบ** (AI ดึงตรงได้)
3. **HEC-RAS 1D แม่น้ำหลักก่อน** (งานค้างเดิม — ใช้หน้าตัดจริง 5 สถานี) → ตรวจ Q/ระดับ Ny.7
4. **ขยาย 2D พื้นที่ อ.เมือง** (เฉพาะที่ราบเมือง ~100 ตร.กม. ไม่ใช่ทั้งลุ่ม) → คาลิเบรตกับ S1 452 ตร.กม.
5. **สร้างแผนที่ 11 ชิ้นแบบ RODDSS** จากผล 2D — ฉากฝนจริง ก.ย. 69 ก่อน แล้วฉากทัศน์ 500 มม./วัน
6. **ขยายลุ่มอื่น** ตามข้อมูลข้อ 1–3 ที่ได้

**เวลาโดยประมาณ**: ขั้น 1–3 = สัปดาห์ (AI ทำได้เยอะ) · ขั้น 4–5 = เดือน (ต้องตรวจโดยวิศวกรน้ำ)
