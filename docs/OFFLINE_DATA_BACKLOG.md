# คลังรายการข้อมูลที่ไม่มีออนไลน์และต้องรอดำเนินการ (OFFLINE_DATA_BACKLOG)

> เอกสารบันทึกรายการข้อมูลสำคัญและแผนงานวิเคราะห์ที่จำเป็นต่อการสืบสวนชลศาสตร์และการบริหารจัดการน้ำ
> แต่**ไม่มีให้บริการผ่านระบบออนไลน์หรือ API สาธารณะ** หรือต้องใช้เวลาพัฒนาแบบจำลองมิติสูง
> ต้องใช้กระบวนการยื่นขออย่างเป็นทางการ (พ.ร.บ. ข้อมูลข่าวสารของราชการ พ.ศ. 2540 / หนังสือขอความอนุเคราะห์ทางวิชาการ / งานสำรวจภาคสนาม)
> ได้รับการสกัดและจัดหมวดหมู่จากการตรวจทานอิสระ (Independent Audit & Red-Team Reviews ทุกรอบ)
> · ปรับปรุง 18 ต.ค. 2569 (รอบกลั่นกรองที่ 5): เพิ่ม FOI-19 · MODEL-04 · ตารางเชื่อมรหัส B-01…B-09 และทะเบียนงานคงค้าง R6-01…R6-21 (หัวข้อ 6)

## 5. ขั้นตอนการแปลงข้อมูลเข้าสู่คลังหลักฐาน (Ingestion Workflow เมื่อได้รับข้อมูล)

เมื่อได้รับชุดข้อมูลใดตามรายการข้างต้น จะต้องปฏิบัติตามกฎของโปรเจกต์ทันที:
1. **จัดเก็บในโฟลเดอร์เฉพาะ**: ลงใน `data/<โฟลเดอร์>/` พร้อมบันทึก `manifest.md` ระบุชื่อผู้ให้, วันที่รับ, และวิธีการได้มา
2. **คำนวณรหัสตรวจความสมบูรณ์**: คำนวณ SHA-256 สำหรับทุกไฟล์ และบันทึกลง `_hashes.txt`
3. **ไฟล์ขนาดใหญ่ (>100MB)**: ปฏิบัติตามนโยบาย `disk-only` ไม่นำเข้า git ตาม `.gitignore`
4. **ตรวจสอบกฎหมายและความเป็นส่วนตัว**: ตรวจสอบตามมาตรฐาน `docs/LEGAL_REVIEW.md` (ตัดข้อมูลระบุตัวบุคคลตาม PDPA ออกก่อนเผยแพร่)
