# กติกาเทียบฝนก่อนเหตุการณ์กับค่าควบคุมของเรดาร์ — กำหนดไว้ก่อนคำนวณฝน

> **ตั้งเมื่อ**: 28 ต.ค. 2569 · **ก่อน**: คำนวณฝนรายหน้าต่างใด ๆ หรือเปิดดูฝนวันที่ 8–22 ก.ย. ของจุดฝนทั้ง 13 จุด
> **ที่มา**: รีวิวรอบ 9 (CS F-02, GM F-02, CS F-04) — ค่าควบคุมของเรดาร์ (รอบถ่ายฉากอ้างอิงหลักเทียบฉากอ้างอิงทางเลือก) สูงถึงร้อยละ 40–50 ของค่าสูงสุดในสองลุ่ม แต่ข้อความรายงานยัง "แยกสาเหตุไม่ได้" ว่าเกิดจากฝนก่อนหน้า น้ำในนา หรือสัญญาณรบกวนของวิธีตรวจจับ — เอกสารนี้ตั้งกติกาตรวจเฉพาะข้อ "ฝนก่อนหน้า" ด้วยข้อมูลที่มีอยู่แล้ว
> **ลักษณะงาน**: บรรยายเท่านั้น · **ไม่มีเกณฑ์ผ่าน/ตก** · ไม่ใช้ตัดสินว่าค่าสูงสุดของลุ่มถูกหรือผิด · ผลออกทางใดก็รายงานตามนั้น

## 1. คำถาม

ฝนระหว่างวันถ่ายฉากอ้างอิงทางเลือกกับวันถ่ายฉากอ้างอิงหลัก (ราว 12 วัน ก่อนฝนใหญ่เริ่ม 20 ก.ย.) สอดคล้องกับขนาดค่าควบคุมของแต่ละลุ่ม/วงโคจรหรือไม่ — และต่างวงโคจรในลุ่มเดียวกัน (ฝนช่วงเดียวกัน) ค่าควบคุมต่างกันเพียงใด

## 2. ข้อมูล (ไม่ดึงเพิ่ม)

- **ฝน**: `data/22_goal6_network/raw/rain_obs_2026/*.json` — ฝนรายวัน (เวลาไทย) ของ Open-Meteo/ERA5 ต่อจุด 13 จุด ใน 6 ลุ่ม (ตัวสร้าง `analysis/goal6_rain_obs_2026.py`) · เป็น **ค่าจากแบบจำลองวิเคราะห์ซ้ำที่จุดเดียว ไม่ใช่เครื่องวัดฝน** · ผลลัพธ์จะบันทึก SHA-256 ของไฟล์ฝนทุกไฟล์
- **ค่าควบคุมและวันถ่าย**: `analysis/goal6/s1_ref_sensitivity.json` (บางปะกง) และ `s1_ref_sensitivity_<ลุ่ม>.json` (บทบาท `control_primary_reference_pass`, สถานะ `ok`) · เวลาถ่ายฉากอ้างอิงหลักและฉากทางเลือกอ่านจากแถว `plan` ของ `data/22_goal6_network/raw/s1_audit/s1_audit_queue_sens*.json` (ชื่อฉาก = เวลา UTC → แปลงเป็นเวลาไทย +7 ชม.)

## 3. หน่วยวิเคราะห์ (ตรึง)

คู่ (ลุ่ม, วงโคจร) ที่มีค่าควบคุม และมีฉากทางเลือก = **13 คู่** (บางปะกง 3 · ป่าสัก 3 · แม่กลอง 2 · ท่าจีน 2 · ปิง–เจ้าพระยา 2 · กรุงเทพฯ ตอนล่าง 1) — จำนวนนับจากข้อมูลนำเข้าก่อนดูฝน · **ไม่ตัดคู่ใดออก** แม้ค่าควบคุมเป็น 0 หรือความครอบคลุมต่ำ

## 4. ฝนต่อคู่ (ตรึง)

ฝนของลุ่ม = ค่าเฉลี่ยถ่วงน้ำหนักเท่ากันของทุกจุดฝนของลุ่มนั้นในไดเรกทอรีฝน · คำนวณสามค่าต่อคู่ (วันที่ = วันตามปฏิทินเวลาไทย; D_alt = วันถ่ายฉากทางเลือก, D_pri = วันถ่ายฉากหลัก):

| ค่า | หน้าต่าง |
|---|---|
| **A แคบ** | วัน d ที่ D_alt < d < D_pri (ไม่รวมสองวันถ่าย) |
| **B กว้าง** | วัน d ที่ D_alt ≤ d ≤ D_pri (รวมสองวันถ่าย) |
| **C ก่อนถ่าย** | สามวันก่อน D_pri (D_pri−3 ถึง D_pri−1) |

ที่ต้องมีทั้ง A และ B เพราะฝนรายวันบอกไม่ได้ว่าฝนตกก่อนหรือหลังเวลาถ่าย (ฉากถ่ายราว 06:00 หรือ 18:30 น.) — ทั้งสองค่าเป็นขอบบน/ล่างของฝนจริงระหว่างสองฉาก · ไม่เลือกค่าใดค่าหนึ่งภายหลัง

## 5. ตัวชี้วัดที่จะรายงาน (ทั้งหมด ไม่เลือกบางตัว)

1. ตาราง 13 แถว: ลุ่ม · วงโคจร · เวลาถ่ายทั้งสองฉาก (เวลาไทย) · ฝน A, B, C (มม.) · ค่าควบคุม (ตร.กม.) · ความครอบคลุมของรอบถ่าย
2. สหสัมพันธ์ลำดับของสเปียร์แมน (ค่าเฉลี่ยลำดับเมื่อค่าเท่ากัน) ระหว่างค่าควบคุมกับ A, B, C — พร้อมจำนวนคู่ (13) · **ไม่รายงานค่า p หรือใช้ป้ายนัยสำคัญ** (13 คู่ไม่เป็นอิสระต่อกัน: สามหน้าต่างเวลาซ้อนกันแทบทั้งหมด และคู่ในลุ่มเดียวกันใช้ฝนชุดเดียวกัน)
3. สหสัมพันธ์ลำดับเดียวกันของ "ค่าควบคุม ÷ ความครอบคลุม" กับ A, B, C (ปรับขนาดคร่าว ๆ ตามส่วนของลุ่มที่ฉากครอบ)
4. **เทียบภายในลุ่ม** (เฉพาะลุ่มที่มีค่าควบคุม ≥ 2 วงโคจร): อัตราส่วนค่าควบคุมสูงสุดต่อต่ำสุด (ถ้าต่ำสุดเป็น 0 ให้รายงานว่าไม่นิยาม) เทียบกับผลต่างฝน A ระหว่างวงโคจรเดียวกัน (มม.) — ใช้บอกว่าฝนต่างกันเท่าใดเมื่อค่าควบคุมต่างกันมาก
5. ช่วงของฝน A ข้ามจุดฝนภายในแต่ละลุ่ม (ต่ำสุด–สูงสุดต่อจุด) เพื่อให้เห็นความไม่เป็นเนื้อเดียวของฝนในลุ่ม

## 6. ถ้อยคำในรายงาน (ตรึงก่อนดูผล)

- ประโยคในรายงาน 3 คำนวณจากผล (ค่าตัวเลขเท่านั้น) และต้องมีข้อจำกัดครบ: ฝนเป็นค่าแบบจำลองที่จุดเดียวต่อบริเวณ · 13 คู่ไม่เป็นอิสระ · หน้าต่างฝนซ้อนกัน · ไม่ใช่ข้อสรุปเรื่องสาเหตุ
- ห้ามเขียนว่าฝนเป็น/ไม่เป็นสาเหตุของค่าควบคุม · ห้ามใช้ผลปรับตัวเลขค่าสูงสุดของลุ่ม · สถานะ "ยังแยกสาเหตุไม่ได้" ในข้อความเดิมคงอยู่เว้นแต่ผลทำให้ต้องแก้ถ้อยคำอย่างชัดเจน และการแก้ถ้อยคำนั้นจะบอกที่มาจากผลนี้
- ถ้าความสัมพันธ์ออกบวก ลบ หรือไม่มี ก็พิมพ์ค่าตามจริง

## 7. สิ่งที่ห้ามเปลี่ยนหลังดูผล

หน่วย 13 คู่ · นิยามหน้าต่าง A/B/C · จุดฝนของลุ่ม (ทุกจุดในไดเรกทอรี) · ตัวชี้วัดข้อ 5.1–5.5 · แหล่งฝน (ไม่เพิ่มหรือเปลี่ยนแหล่งภายหลังเพื่อให้ผลดูดีขึ้น — การเพิ่มสถานีวัดฝนภาคพื้นดินเป็นงานแยกที่ต้องมีกติกาใหม่) · วิธีคิดสหสัมพันธ์
