# กติกาหน่วยวิเคราะห์น้ำเรดาร์เป็น "วงโคจร × วัน" รวมชิ้นส่วน · ขอบเขตสูงสุดรวมทุกวัน · ความไวต่อวันของฉากอ้างอิง — กำหนดไว้ก่อนดูผล (27 ต.ค. 2569)

> ที่มา: หลังจับฉากอ้างอิงตามวงโคจรสัมพัทธ์ ตัวเลขสูงสุดต่อลุ่มยังเป็นรายชิ้นส่วนฉาก (slice) ซึ่งขึ้นกับว่าชิ้นไหนใหญ่ และฉากสูงสุดครอบคลุมกริดเพียงบางส่วน (ปิง–เจ้าพระยาราวหนึ่งในห้า) · เอกสารนี้ตกลงวิธีก่อนคำนวณ (ยืนยันด้วยเวลาคอมมิต) · ไม่มีเกณฑ์ผ่าน/ตก

## 1. หน่วยวิเคราะห์ = วงโคจรสัมพัทธ์ × วันถ่าย (เรียกว่า "รอบถ่าย")

- รวมทุกชิ้นส่วนของรอบถ่ายเป็นภาพเดียว: ภาพ VH/VV หลัง = เติมค่าที่ชิ้นแรกไม่มีด้วยชิ้นถัดไป (ลำดับตามเวลา) · ภาพอ้างอิงเป็นภาพรวมเดิมตามกติกาการตรวจ · ตัดน้ำด้วยกฎตรึงเดิมครั้งเดียวต่อรอบถ่าย (`detect`)
- ชื่อรอบถ่ายในสรุป = ชื่อชิ้นส่วนแรกของรอบ (คงรูปชื่อเดิมเพื่อให้ผู้ใช้ผลอ่านวัน/เวลาได้) บันทึกรายชื่อชิ้นส่วนทั้งหมดไว้ที่ `slices`
- ส่วนที่ครอบคลุม (`coverage`) = สัดส่วนของกริดลุ่มที่ภาพรวมหลังและภาพอ้างอิงมีข้อมูลทั้งคู่ — แสดงกำกับทุกตัวเลขพื้นที่
- รอบถ่ายที่เป็นฉากอ้างอิงเองคงไว้ (น้ำเป็น 0 ตามข้อตกลง `reference == scene`)
- ค่าตัวเลขรายชิ้นส่วนเดิมไม่เก็บต่อในสรุป (ยังทำซ้ำได้จากสคริปต์ด้วยการแยกชิ้นส่วน)

## 2. ขอบเขตน้ำสูงสุดรวมทุกวัน (รายงานคู่ ไม่แทนค่าสูงสุดต่อรอบถ่าย)

- ต่อลุ่ม: พื้นที่ของการรวม (OR) มาสก์น้ำของทุกรอบถ่ายที่ไม่ใช่ฉากอ้างอิง พร้อมสัดส่วนของกริดที่มีรอบถ่ายใดรอบหนึ่งครอบคลุม และจำนวนรอบถ่าย
- ต้องระบุคู่กันเสมอว่า **ไม่ใช่น้ำท่วมพร้อมกัน** (รวมหลายวัน) และเป็นขอบบนของขอบเขตน้ำท่วมที่เรดาร์เห็นตลอดช่วง

## 3. ความไวต่อวันของฉากอ้างอิง (ลุ่มบางปะกง–ปราจีนบุรีเท่านั้น)

- ฉากอ้างอิงทางเลือก = รอบถ่ายของวงเดียวกันก่อนหน้าฉากอ้างอิงหลักราว 12 วัน (ล่าสุดที่เก่ากว่าฉากอ้างอิงหลักอย่างน้อย 6 วัน) ที่ทับกรอบลุ่ม — ดึงเฉพาะที่ยังไม่มีบนดิสก์
- ตัดน้ำซ้ำทุกรอบถ่ายของลุ่มด้วยฉากอ้างอิงทางเลือก แล้วรายงานพื้นที่ต่อรอบถ่ายเทียบฉากอ้างอิงหลัก และค่าสูงสุดต่อลุ่มทั้งสองแบบ
- วัตถุประสงค์: ดูว่าน้ำที่ขังตามฤดูในนาข้าวระหว่างสองสัปดาห์ ทำให้พื้นที่น้ำใหม่ขยับเท่าไร · ติดป้าย "ไวต่อฉากอ้างอิง" เมื่อค่าสูงสุดเปลี่ยนเกินร้อยละ 10 เป็นเพียงป้ายอ่านตาราง · ไม่เลือกฉากอ้างอิงตามผล และไม่เปลี่ยนค่าหลักตามผลนี้

## 4. การรายงาน

- ตัวเลขสูงสุดต่อลุ่มในรายงาน 3–4 และเอกสารเปลี่ยนเป็นรอบถ่าย (ค่าเก่าลงบัญชีค่าที่เลิกใช้) พร้อมสัดส่วนครอบคลุม · ข้อ 2 และ 3 เพิ่มในข้อจำกัดข้อ (7) ของรายงาน 3 ด้วยประโยคที่คำนวณจากข้อมูล

## 5. ห้ามทำหลังดูผล

เปลี่ยนวิธีรวมชิ้นส่วน กฎตัดน้ำ ขีดร้อยละ 10 วันของฉากอ้างอิงทางเลือก ชุดลุ่ม หรือเลือกเฉพาะรอบถ่ายที่ให้ผลน่าพอใจ
