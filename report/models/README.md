## ไม่ใช่ตัวเลขทางการ (ข้อสมมติ — อย่านำไปอ้างเป็นแบบ)
1. **แนวคลอง (พิกัด)** ประมาณจากหมุด กม. ในแผนที่ KML ของโครงการ ไม่ใช่แนวกึ่งกลางตามแบบก่อสร้าง · หมุด กม.0–3.5 อยู่คนละสายกับ กม.4 ขึ้นไป จึงต่อเป็นเส้นตรง
2. **ระดับท้องไซฟอน** (ตั้งให้บนสุดอยู่ใต้ท้องคลอง 1 ม. · บ่อดิ่งเชื่อมท่อระบายน้ำ 15 ม. กับท่อไซฟอน — ตารางไม่ระบุรูปแบบการเชื่อม) · **ความสูงสะพาน** (ท้องสะพานอยู่ระดับสันคัน) · **ตอม่อ** · **รางสะพานน้ำ** (สูงเหนือสันคัน 3 ม.) · **ทางสัญจรบนประตูระบายน้ำ**
3. **เขตทาง (RL/RR)** ไม่วาดในแบบจำลอง (ตารางไม่ระบุจุดเริ่มวัด) — ระบุค่าในป้ายกำกับ กม.23 (85 → 60 ม. ข้างละ)
4. **ช่วง กม.0–23** ตารางพิมพ์ A = 480 ตร.ม. แต่คำนวณจาก B, Z, ทางเลียบได้ 490 (ต่าง 2%) — แบบจำลองใช้ B, Z ตามตาราง

## การแก้ไขล่าสุด (ผลตรวจจากการเปิดใน SketchUp)
- ท่อไซฟอน: ต่อเป็นห่วงเดียว ท่อระบายน้ำ → บ่อดิ่ง → ท่อไซฟอน → บ่อดิ่ง → ท่อระบายน้ำ (เดิมแยกเป็น 3 ชิ้น)
- ถอดเส้นสีเหลือง (เขตทาง) ออก — วัดจุดเริ่มไม่ได้จากตาราง
- ท้องคลองช่วง 1 ยึดค่ากำกับ กม.22.9 (−0.55) ลาด ~1:9,900 ตามตาราง 1:10,000 แล้วลดฉับพลันเป็น −1.05 ที่ กม.23 (ขั้นหน้าประตู 0.5 ม. ตามรูป 2.3.2-9: ผิวน้ำ 6.45 → 5.95)
